# Dashboard wireframes

## Shared shell

`[brand + private operational intelligence] [last refreshed / DB status]`

Sidebar: navigation, read-only system flags, and compact filters. Main content uses
section headers, bordered cards, semantic badges, and a single dominant action path.

## Overview

Header → KPI strip → funnel/classification/match charts → location and cost trends →
recent high-priority leads.

## Lead inbox

Header → search and reset → quick chips → filter form → result count/sort/pagination →
lead table → selected-lead preview and sanitized CSV export.

## Lead detail

Lead selector → summary card → score explanation → source card → match cards →
workflow form/audit → read-only Telegram history.

## Inventory

Validation banner → three active property cards → secondary inventory table. Missing or
invalid inventory is a warning state, never a fallback.

## Matching review

Tier tabs (Exact / Nearby / Tentative / No match / Legacy historical) → side-by-side
lead and inventory facts → score/reasons/warnings → confirmation-required treatment.

## Pilot analytics

Run-log note → per-run funnel and classification → target-area/unknown and budget
confidence → tier/cost trends → cumulative and manually-reviewed quality panels.
